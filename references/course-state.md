# 课程记录与继续学习

## 保存位置

使用用户指定的课程目录；没有指定时，可在当前可写工作区创建 `exam-prep/课程简称/`，先检查同名目录与文件。已有同课程记录则读取后续写；名称相同但教材、学期不同，创建不同子目录。未获宿主文件访问能力时，在聊天给出可复制的进度记录，并说明需要下次带回。

基础记录用 `course.md`、`progress.md`、`mistakes.md` 即可，按需要创建；不用为了模板生成大量空文件。教材保留原位置，在记录里引用，不移动或复制整本书。学生材料、答案、记录不放进 Skill 目录，不为这些学习笔记初始化 Git 或上传远程。

## course.md

记录课程名、教材名称/版次、课程目标、日期与时区、每日时间、题型/总分/开闭卷。缺失值写“未知”，假设写“暂按……”，不把默认值变成已确认事实。

来源表至少包含：来源 ID、文件/附件名称、可访问路径或附件定位、资料类型、实际已读范围、不可读页、页码规则。附件只在当前会话可访问时明确记下该限制，不能编造永久路径。

记录教师明确范围及其来源、学生选择的复习范围、未覆盖内容。材料版本变化时重新核对受影响的范围和练习，不沿用旧定位。

## progress.md

每个考点记录：材料定位、优先级及依据、最近练习日期、题号、独立/提示/看过答案状态、分数/满分、尚存问题、下一次行动。推荐状态词为“未诊断、需讲解、提示后会做、独立通过、待延后复测”；根据实际证据升级或降级，不默认以一次作答代表整章。

保留当前待答题的完整题干、分值、目标和已展示的提示。需要跨会话稳定评分时，将预先拟定的参考答案和评分点保存为单独的 `answer-keys/题号.md`，不在发题时展示内容；它只是输出分离，不是访问控制。新会话先读取待答题与评分记录，避免悄悄换题、改分值或遗失进度。

日期应取用户时区；间隔按表现和考试期限调整。可用“当天重练、次日短测、数日后混合复测”作初始建议，未实际安排提醒时只称复习计划。

## mistakes.md

每项保留：题号与题干/链接、材料依据、学生实际作答、练习得分、错误诊断、修正要点、变式题、复测日期/结果。看过解析不等于错题已解决；独立完成变式或延后复测后才记录进展。只保留学习需要的信息，避免重复抄录整章教材。

## 更新与恢复

先读旧记录再作局部更新，保留之前的作答证据。会话结束或完成一个学习单元后保存本轮变化，并用一句话告诉学生保存路径和下次入口。

继续学习时顺序为：读取课程目标与来源可用性 → 恢复待答题或到期复测 → 针对弱点练习 → 新知识。用户明确要跳章、看答案或改变目标时随之调整，不用记录强制锁定学习路径。
