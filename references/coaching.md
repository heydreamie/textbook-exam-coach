# 辅导、练习与评分

只读取本轮需要的部分。课程材料的真实范围和符号约定优先于通用模板。

## 讲解一个考点

让学生知道它解决什么问题、题目有什么识别信号、需要满足哪些条件，以及答题时怎样展开。一个合适的例题通常比大量定义堆叠更有效。例题与独立练习采用不同数据/情境；如果练习恰好复用了已展示的答案，要标记为模仿练习，不能作为独立掌握证据。

按课程类型调整答题训练：

| 类型 | 训练与检查重点 |
|---|---|
| 数学、理工与定量课程 | 已知/求解对象、建模、公式条件、推导步骤、单位/边界、计算结果合理性；证明题区分已知、待证、逻辑依据 |
| 人文、社科与论述题 | 概念边界、核心论点、因果/比较关系、材料证据、限定条件；教组织答案，不把所有题套成固定几句话 |
| 计算机课程 | 概念条件、执行跟踪、复杂度、边界输入、算法或代码正确性；运行结果和手工推演要分清 |
| 案例或应用题 | 识别问题、选择理论、把事实与规则对应、分析备选解释、给出有条件的结论 |

## 出题前

- 每道题确定考点、范围依据、题型、难度理由、参考解答和评分点，再发给学生。评分点的分数加总必须等于题目分值。
- 参考解答需能从已核对材料和明确推导得到。检查条件是否足够、选择题是否确实只有所声明数量的正确选项、干扰项是否可区分；有歧义则先修题。
- 计算题独立复算；复杂数值/代码使用可用工具验证，并考虑定义域、退化情况和舍入。未运行时不要声称运行通过。
- 外部原题、改编题、原创题明确区分。无来源支持时，不能标成某校历年真题。
- 练习评分标准可以自行拟定，但必须标成“练习评分”；有教师正式标准时引用并按其执行。

## 互动练习

默认只显示题干、必要数据、分值和作答要求。选择题选项在长度、语气、格式上平行，避免答案总在同一位置。发题后等待作答，不自问自答。当前聊天不能提供严格隔离的考场环境，不声称答案被技术锁定。

学生卡住时，先给一个不会直接揭晓答案的提示；再按需要给关键关系、部分步骤，最后完整解答。学生要求直接看答案时尊重选择，记录为“已看解答”，不判定独立通过。

学生答错后用下面的顺序反馈：

1. **本题得分/满分**与依据。只有最终式时，按实际提交内容和既定规则给暂评分，说明哪些步骤未展示、因此无法确认；不补写假想步骤替学生得分。题意或评分规则本身有关键歧义时，标出暂不能确定的分项并澄清；已能判断的错误和下一道练习仍可先给出。
2. **已做对的步骤**，以及**第一个关键错误**。
3. **修正后的步骤/解释**，引用材料位置；后续由同一个错误传播的结果，按既定规则处理，避免重复扣分。
4. **一条可执行的改进**及一道短变式题，不用“粗心”替代具体诊断。

学生之后补交原有过程时可以复核得分；在看到解答后重新作答则记为订正，不冒充原始独立表现。

记录错误类型：概念/条件误用、方法选择、推导或论证缺口、运算、单位或符号、读题、表达、时间安排。分类不确定时说明，不进行性格判断。学生提出异议时重查题目、来源和评分规则；若是题目/答案问题，撤销不当扣分并更新记录。

## 模拟考试

先用已知考试范围、题型、总分和时长组卷。信息缺失时明确给出“练习卷方案”的假设，不冒充真实考试结构。覆盖表记录每题的考点、材料依据和分值，检查总分、范围和题目重复。

题目文件与答案文件分开，答题前默认只交题目。用户交卷或要求解析后再展示答案。仅使用实际时间信息报告耗时；没有计时工具时让学生自计时，不伪造自动倒计时。

考后报告给出分题得分、错误集中点、剩余时间内最值得修补的 2–3 项及下一次复测。分数描述为这份练习的表现，不能当成正式考试预测。
